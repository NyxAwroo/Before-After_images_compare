# Suggestions d'améliorations — Comparateur Pro

Idées d'évolution pour les versions futures.
Ce document sert de réservoir à prioriser.

---

## ✅ Traité récemment

- **(img1) Menu clic droit réparé** — résolu en 3.2.0 : le chemin figé des
  `.reg` cassait le lancement après déplacement du dossier. `.reg` retirés
  du dépôt au profit de `install_raccourcis.bat` (portable).
- **18. Liste des fichiers récents** — fait en 3.2.0 : bouton « Récents »
  dans le panneau gauche, historique persistant de 10 comparaisons.
- **17. Traitement par lot de compilations** — fait en 3.2.0 : volet
  « Packs de compilation » dans l'onglet Compilation ; chaque pack devient
  une planche, tous partagent le gabarit ; génération de masse en un clic.

---

## ⚙️ Confort, interface et flux de travail

19. **Glisser-déposer depuis le navigateur web** — accepter les images
    glissées directement depuis une page web, pas seulement depuis
    l'explorateur de fichiers.

23. **Profils de réglages** — enregistrer et recharger des ensembles de
    réglages complets (couleurs, formats, étiquettes) selon le type de
    travail.

24. **Mise à jour intégrée** — une vérification de version qui signale la
    disponibilité d'une nouvelle release sur GitHub.

---

Conclure le tout, une fois validé, par un `.bat` d'installation pour les
novices qui découvrent le logiciel sur GitHub.
