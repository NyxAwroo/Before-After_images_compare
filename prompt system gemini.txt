🛠️ Prompt de Reprise : Projet "Comparateur Pro" v2.0

Contexte du Projet :
Développement d'un logiciel de comparaison d'images professionnel. L'outil est écrit en Python 3 avec PyQt5, OpenCV et Pillow.

Architecture Technique :

Fichier principal : comparateur_app.py (Localisation : D:\Documents\Python Scripts\comparaison image AVANT-APRES\).

Configuration : comparateur_config.json (mémorise les réglages UI en temps réel).

Intégration Windows : Fichiers .reg (FR/EN) utilisant pyw pour un lancement silencieux via le clic droit sur Images et Dossiers.

Fonctionnalités Implémentées :

Moteur de Rendu : Comparaison multi-images avec curseurs mobiles et zoom/pan synchronisé.

Affichage "Pro" : - Sticky Labels : Infos épinglées aux bords, redimensionnées dynamiquement.

Snapping : Aimantation des curseurs à 25%, 50% et 75%.

Mode Blink : Touche Espace pour alterner entre référence et vue actuelle.

Analyse & Alignement :

Auto-Alignement 2D : Algorithme Affine Partial 2D (stable) pour caler des images décalées sans déformation 3D.

Multi-Heatmap : Carte thermique cumulative (toutes images vs référence) dans une fenêtre indépendante.

Multilingue (i18n) :

Dictionnaire interne (LANGUAGES) gérant le Français et l'Anglais.

Détection automatique de la langue système au premier lancement.

Exportation Perfectionnée :

Moteur 1:1 : Redessine la scène sur un QPixmap virtuel à la taille originale (sans fond noir, ni bordures logicielles).

Filigrane (Watermark) : Texte personnalisable incrusté à l'export.

Stabilité & Fail-safe :

Correctif pyw : Bypass de stdout/stderr via io.StringIO() pour éviter les plantages silencieux Windows.

Intercepteur de crash : sys.excepthook personnalisé pour afficher une boîte de dialogue en cas d'erreur fatale.

Gestion de Session : Les réglages Premium persistent, mais la liste des packs est vidée à la fermeture (closeEvent).

Instructions de Développement :

Conserver le thème sombre et l'esthétique Premium.

Toujours vérifier la syntaxe des fichiers .reg (les guillemets internes doivent être échappés \" et les chemins doublés \\).

Maintenir la logique de regroupement des instances (cache temporaire) pour le clic droit multiple.

Privilégier les solutions sans dépendances lourdes hors OpenCV/PIL.
